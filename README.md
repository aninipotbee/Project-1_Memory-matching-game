# Memory Matching Game

Hi There! We are Group 7 CS students.
 We have here a clean, interactive web-based memory matching card game designed to test and improve visual memory. Players flip pairs of cards to find matching icons, aiming to clear the board in as few moves and as quickly as possible. Built with python, it has responsive layouts and 3 difficulty levels.

## Installation and Run Instructions:

Python 3.x (Tkinter is included by default with standard Python installations).

Control and UI Interaction
1. Name Input (Entry field)
Type your player name on the start screen before clicking "START GAME".
2. Card Buttons (? Grid Buttons)
Click any hidden card button to flip it and reveal its symbol (A, B, C, etc.).
3. PEEK Button
Click to temporarily uncover all unmatched cards on the grid for 2.5 seconds. Costs 1 turn and 1 peek charge.
4. HOW TO PLAY Button
Triggers a popup displaying the rules.
5. ​QUIT Button
Displays a dialog box asking for confirmation before closing the application.
6. SEARCH Button (End Screen) 
Type a player's name into the leaderboard search field and click to locate their rank and final score.
7. ​PLAY AGAIN / EXIT Buttons
Restart from the home screen or quit the program.
